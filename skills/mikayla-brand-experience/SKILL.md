# MIKAYLA Brand Experience

Build a fashion intelligence product, not a travel blog, SaaS dashboard, or generic ecommerce storefront.

## Workflow

1. Read `references/brand-system.md`.
2. Identify the user’s single job on the screen.
3. Establish one editorial focal point, one primary action, and a restrained supporting hierarchy.
4. Use real creator, editorial, or user-owned fashion imagery with visible provenance. Never introduce generic travel stock photography.
5. Make every control visibly interactive and complete its empty, loading, success, and error states.
6. Review the screen at desktop and mobile widths before considering it finished.

## Non-negotiables

- Keep the product name in uppercase: `MIKAYLA`.
- Use the primary line `Every city has its own dress code.` or the product line `Dress the City` only where each has a clear role.
- Prefer ivory, black, warm grey, and one restrained metallic accent.
- Use a high-contrast editorial serif for display type and a quiet sans serif for interface text.
- Use generous whitespace, strong alignment, thin rules, and deliberate image crops.
- Avoid gradients, glass effects, rounded SaaS cards, oversized shadows, emoji, novelty icons, and crowded navigation.
- Avoid empty luxury. A beautiful screen that does not help the user discover, plan, reuse, or shop is incomplete.
- Avoid false scarcity, invented live counts, invented engagement, fabricated trend confidence, and unlabelled demo data.
- Preserve accessibility: semantic headings, keyboard operation, visible focus, sufficient contrast, reduced-motion support, and descriptive alternative text.

## Navigation model

Use five plain-language journeys:

- Discover
- Visual Shop
- Plan
- Closet
- Studio

Keep secondary content such as About, Journal, Privacy, affiliate disclosure, and data controls in the footer or account area.

## Completion gate

Confirm that a first-time user can answer all of these without explanation:

- What does MIKAYLA do?
- How do I search a city?
- How do I shop a look?
- How do I upload an itinerary?
- How do I add clothes I already own?
- How do I build and save an outfit?
