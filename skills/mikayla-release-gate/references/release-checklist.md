# MIKAYLA release checklist

## Discover

- City search accepts a supported city and a new city.
- Filters update the visible feed.
- Every image has a source and useful alt text.
- Creator imagery uses an approved platform embed or other permitted display route.
- Every look opens a shopping result.
- Original source links open safely.
- Freshness and fallback labels are accurate.

## Visual Shop

- Image preview works.
- Unsupported files are rejected clearly.
- No-key fallback is honest.
- Detected pieces include accessories.
- All price tiers open useful searches or verified products.

## Plan

- Pasted itinerary creates a schedule.
- Image and PDF inputs are handled.
- Named venues remain visible in results.
- Each event has a complete outfit and rationale.
- Each event offers understated, fashion-forward, and practical directions.
- Calendar, capsule, and packing views remain available after generation.
- Results persist after refresh.

## Closet

- Multiple images can be added.
- User can edit category and item details.
- Items persist after refresh.
- User can delete items.
- Outfit building uses owned pieces.
- Purchase gaps do not duplicate owned pieces.

## Studio

- Each garment row changes independently.
- Complete look remains visible.
- Owned and shoppable pieces are distinguishable.
- Total cost excludes owned pieces.
- Saved look can be assigned to an itinerary slot.

## Saved and private vault

- Inspiration can be saved and removed.
- Uploaded outfit references can be retained privately and removed.
- Saved inspiration, closet count, assembled looks, and itinerary occasions are summarised together.
- Private content never appears in the verified city feed.

## Global

- Navigation and back behaviour work.
- Keyboard focus is visible.
- Menu and drawers close with Escape.
- Forms have labels and clear errors.
- Images do not cause layout shift.
- Mobile layouts work at 390 px.
- Reduced motion is respected.
- Shopping relationship language matches the live configuration: direct retailer searches now, affiliate disclosure only when tracking is active.
- Contemporary shopping appears first while accessible and luxury alternatives remain available.
- Exact and similar matches are never described interchangeably.
- Privacy and deletion controls are discoverable.
- No API key, token, or email credential is committed.
